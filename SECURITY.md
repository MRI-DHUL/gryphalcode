# Security Policy

## Supported versions

The `main` branch is the actively maintained version of GryphalCode.

## Reporting a vulnerability

Please do not disclose suspected security vulnerabilities in public issues.

Report security issues privately to the GryphalCode maintainers with:

- A clear description of the vulnerability
- Affected URL, file, or component
- Reproduction steps or proof of concept
- Security impact and severity estimate
- Any suggested remediation

Do not include credentials, API keys, personal data, or other sensitive information unless strictly necessary.

## Scope

This policy covers the GryphalCode website source code and its CI/CD configuration. Active testing against third-party infrastructure or production systems without authorization is not permitted.
